观察总结

从已核验的公开广告样本归纳，可作为 I MISHANG 内容测试方向。

竞品内容规律

  • 低门槛体验价：RM29.90 高频出现，配合快洗 / 男士 / Hikari 项目建立首次尝试理由。
  • 过程展示：直接拍清洁、面膜与护理步骤，让顾客看到到店会做什么。
  • 降低戒心：“不强销、不绑配套”、免费分享会等信息反复回应美容店常见顾虑。
  • 按问题拆项目：油脂黑头、暗沉光泽、护肤品选错分别使用不同创意，而非只讲品牌。
  • 转化路径：WhatsApp、私讯、线上分享会与商家电话 / 导航并行。

I MISHANG 可测试的内容切口

  • 把一条广告聚焦一个肤况：问题画面 → 护理实拍 → 真实感受 → 体验价格 / 预约方式。
  • 拍完整、真实的护理片段，保留洁面、仪器 / 手法、敷膜等关键过程，避免只有促销海报。
  • 针对怕推销的顾客，把“先分析、再建议、无需购买配套”的流程拍清楚。
  • 按不同分店服务半径制作本地版素材，画面和文案都显示分店 / 预约入口。
  • TikTok 样本付费状态尚未确认；可参考其轻松趋势表达，但不能据此判断广告预算或投放强度。

数据口径 / 使用说明

Meta 视频与 Google 图片均为公开资料页面取得的实际素材；此追踪页记录的是截至 2026-10-19 可见样本，不是完整广告账户导出。Meta“运行至少约 X 天”按首次展示日到观察日估算，Active 状态及广告 ID 以来源页为准。Google 公开库显示最近展示日，但未提供可靠首次运行日。TikTok 区只将可核实的官方公开视频展示为自然内容样本，未找到可以确认的付费广告记录。平台广告库可能按国家、广告主名称或登录状态展示不同结果。
